# formula-mercury-editor
Recipe to install Mercury Editor and related modules for Drupal.

This recipe includes:
- Mercury Editor - Enhanced content editing experience
- Style Options - Adds styling options to paragraphs and other entities
- Config Pages - Configuration entity pages
- ME Config Pages - Mercury Editor integration with Config Pages
- Layout Paragraphs Restrictions - Restrictions for Layout Paragraphs

**Note:** Some modules in this recipe use pre-release versions (dev/alpha) for Drupal 11 compatibility.
