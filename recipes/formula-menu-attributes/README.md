# formula-menu-attributes
Recipe to install Menu Attributes module for Drupal.

**⚠️ WARNING:** This module currently has NO stable Drupal 11 release. The module is minimally maintained with maintenance fixes only.

Please check the [Menu Attributes project page](https://www.drupal.org/project/menu_attributes) for Drupal 11 compatibility status before using this recipe.

You may need to:
- Use a development version: `"drupal/menu_attributes": "2.0.x-dev"`
- Consider alternative modules
- Wait for a stable release
